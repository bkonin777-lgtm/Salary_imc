Projet : “Analyse interactive des salaires d’entreprise”

Contexte : Vous travaillez comme analyste de données dans une entreprise de télécommunications (inspirée de Sonatel). La direction RH souhaite mieux comprendre la distribution des salaires des employés afin de :

Identifier les profils à hauts revenus

Visualiser la répartition des salaires par département et par genre

Exporter les agents au-dessus d’un certain seuil

Votre mission : Créer une application web interactive avec Streamlit permettant de :

Importer un fichier CSV de salaires

Nettoyer les données

Afficher des statistiques et visualisations

Permettre un filtrage dynamique selon un seuil

Télécharger les agents filtrés
